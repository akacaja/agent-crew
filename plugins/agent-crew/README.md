# agent-crew (plugin)

Pipeline de agentes especialistas para o Claude Code, com um mentor que explica cada etapa no nível e no idioma da pessoa. Comandos: start, new-project, card, mentor, profile, pause e resume. A documentação completa, com instalação, níveis, sistema de design e regras de segurança, está no README da raiz do repositório: https://github.com/akacaja/agent-crew
