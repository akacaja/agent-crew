---
description: Define o nível de explicação do kit (iniciante, intermediário ou avançado)
argument-hint: (opcional) o nível
---

Siga as instruções de `templates/set-item.md` (em `${CLAUDE_PLUGIN_ROOT}/templates/`) para o item **Nível** do perfil.

Valor pedido: $ARGUMENTS

Opções:
- Iniciante: estou começando, quero explicações completas.
- Intermediário: já criei alguns projetos, quero explicações curtas.
- Avançado: sou desenvolvedor ou já domino; quero só o essencial.

Ao confirmar, conte em duas linhas o que muda, usando a tabela "Como o kit se comporta em cada nível" do perfil.
