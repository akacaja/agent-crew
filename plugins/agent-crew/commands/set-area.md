argument-hint: (opcional) a área, por exemplo "design"

Siga as instruções de `templates/set-item.md` (em `${CLAUDE_PLUGIN_ROOT}/templates/`) para o item **Área de atuação** do perfil.

Valor pedido: $ARGUMENTS

Opções: design, produto, desenvolvimento, dados, outra (a pessoa escreve qual).

Ao confirmar, dê um exemplo curto de analogia que o kit vai usar nessa área (por exemplo, para design: "um componente reutilizável é como um componente do Figma com instâncias").
